C++ Learning Journey

About This Project

This repository contains my first C++ programming project, a text-based RPG that I started building while learning the fundamentals of programming.

I'm currently pursuing a Bachelor's Degree in Cybersecurity with an emphasis in Digital Forensics. I decided to learn programming to expand my technical knowledge and develop skills that I can apply to future projects.

This game is a work in progress and serves as a way for me to practice writing code, understanding programming logic, and troubleshooting errors.

What I've Learned

Throughout this project, I've practiced several fundamental C++ concepts:

Variables and Data Types — Storing and modifying information such as player health and gold.

Conditional Statements — Using if, else if, and else to control program behavior.

Loops — Using while loops to repeat actions.

User Input — Using std::cin to allow players to make decisions.

Console Output — Using std::cout to display information.

Basic Game Logic — Creating player choices, combat interactions, and simple game mechanics.

Project Features

The text-based RPG includes basic gameplay mechanics such as:

Player health and gold management.

Player choices and interactions.

A simple enemy encounter.

Basic attack and escape options.

Conditions that determine whether the player survives.
